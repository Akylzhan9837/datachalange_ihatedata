Запасные модели и ключи: 3.5 → 3.8 → 2.5

Спорный случай — 3 прогона и голосование

Звонки — тем же конвейером по транскрипту, запись — для проверяющего при апелляции (ADR-004)

Главный принцип: модель не считает баллы. Диалог с пронумерованными репликами и промпт, собранный из чек-листа, уходят в Gemini одним вызовом. Модель рассуждает по шагам и по каждому критерию отвечает и указывает номера реплик. Код проверяет ответ — допустимое значение, реплика существует, «Да» только с доказательством. Не прошло — пометка для проверяющего, без тихой подмены. Итог, веса и перераспределение N/A считает отдельный модуль с тестами. Если модель недоступна — запасные модели и ключи. Для спорных случаев — три прогона и голосование. Звонки идут тем же конвейером по транскрипту.
