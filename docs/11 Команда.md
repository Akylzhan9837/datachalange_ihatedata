# Команда — кто что делает

> [!important] Одно правило для всех
> Главный критерий жюри — **точность против эталона**. Свободная минута → помоги Б2 с разметкой эталона.

| Код | Роль | Кто | Миссия в одну фразу |
|---|---|---|---|
| **ТЛ** | Тимлид + LLM | Арлан | Оценки системы совпадают с эталоном |
| **Б1** | Бэкенд «данные и процессы» | _имя_ | Всё, что происходит с оценкой после модели, работает и не теряется |
| **Б2** | Бэкенд «точность» | _имя_ | Мы всегда знаем, насколько точна система и где она ошибается |
| **Ф** | Фронтенд | _имя_ | Жюри за 5 минут видит всё, что требует кейс |

---

## ТЛ — тимлид + LLM
**Делает по порядку:**
1. 0:00–0:30 — ведёт калибровку (все размечают 3 одинаковых диалога и сверяются).
2. **К 0:45** — фиксирует формат результата оценки и отдаёт Ф и Б1 ([[02 Чек-лист и правила оценки#Формат результата одного критерия]]).
3. **К T+5** — модель + промпт из чек-листа + `POST /api/evaluate`: один диалог оценён от начала до конца.
4. Делает вторую разметку 10 диалогов (для сверки с Б2).
5. До T+20 — улучшает промпт по метрикам от Б2.
6. Решает спорные вопросы, пишет сценарий демо, **говорит на защите**.

**Файлы:** `server/evaluate.ts`, `server/llm.ts`, `prompts/`, `docs/06`, `docs/07`, `docs/08`, `docs/12`. Личный промпт — `MASTER_PROMPT_TL.md`
**Не делает:** интерфейс, хранение, апелляции.

---

## Б1 — бэкенд «данные и процессы»
**Делает по порядку:**
1. **К T+1** — скелет проекта и прокси к API организаторов (CORS) с кэшем; API чек-листов (получить / сохранить с версией и проверкой); извлечение mp3 из `audio_url`.
2. **К T+3** — хранение результатов оценки: версия чек-листа, модель, стоимость, время. Переживает перезапуск сервера.
3. **К T+7** — API апелляций: подать, решение проверяющего с причиной, пересчёт итога. Хранятся исходная оценка, решение и финал.
4. **К T+10** — пакетная оценка всего набора: прогресс, ретраи при ошибках модели, итоговая стоимость.
5. GitHub, README, запуск на ноутбуке для демо.
6. **T+23** — запускает контрольный набор сразу, как его выдадут.

**Файлы:** `server/index.ts`, `server/store.ts`, `README.md`
**Не делает:** промпт, разметку, интерфейс.

## Б2 — бэкенд «точность»
**Делает по порядку:**
1. 0:00–0:30 — калибровка вместе со всеми.
2. **К T+2** — расчёт баллов `shared/scoring.ts` + тесты: шкалы, N/A-перераспределение, округление, грубая ошибка.
3. Первый час — задаёт вопросы организаторам ([[09 Вопросы организаторам]]), записывает ответы.
4. **К T+5** — размечает первые 10 диалогов эталона, **к T+9** — 20 (все языки + все 5 звонков) → `data/gt/dev_gt.json`.
5. **К T+8** — скрипт `npm run eval`: точность по каждому критерию, ошибка итогового балла.
6. После каждого прогона — список ошибок «диалог · критерий · почему» → ТЛ.
7. Правила-подсказки в коде: первая реплика оператора, было ли прощание, был ли «чат закрыт». Расхождение с моделью → флаг «проверить».

**Файлы:** `shared/scoring.ts`, `data/gt/`, `scripts/eval.ts`, `server/rules.ts`, `docs/06`, `docs/09`
**Не делает:** правит промпт сам (только через ТЛ), интерфейс.

## Ф — фронтенд
**Делает по порядку:**
1. **К T+5** — список диалогов, транскрипт с номерами реплик и карточка результата на тестовых данных: ответ, баллы, вес, обоснование, клик → нужная реплика, N/A с причиной, итог и секции.
2. **К T+9** — редактор чек-листа: добавить/изменить/удалить критерий, вес, тип, шкала, N/A. API чек-листов делает Б1.
3. **К T+12** — апелляция (выбрать критерий + комментарий) и отдельный экран проверяющего — по API от Б1.
4. Плеер звонков с перемоткой к реплике (ссылку на mp3 отдаёт Б1).
5. Кнопки «Оценить», «Оценить весь набор», прогресс, стоимость.
6. Полировка; на защите — **за рулём** (кликает, пока ТЛ говорит).

**Файлы:** `web/`
**Не делает:** серверную логику, промпт.

## Кто кому что отдаёт
| От | Кому | Что | Когда |
|---|---|---|---|
| ТЛ | Ф, Б1 | формат результата оценки | 0:45 |
| Б1 | Ф | эндпоинты оценок и апелляций (таблица в README) | по готовности |
| Б2 | ТЛ | метрики + список ошибок | после каждого прогона |
| ТЛ | Б2 | новая версия промпта для прогона | после каждой правки |

## Правила
- Каждый работает **в своих файлах** — так не будет конфликтов в Git.
- Чек-лист JSON меняет только ТЛ, `shared/scoring.ts` — только Б2. Остальным — с предупреждением в чате.
- Синк каждые 3 часа, 10 минут: сделал / блокирует / метрики.
- Свою задачу отмечаешь в [[05 План]].
- **T+20 — фича-фриз.** Дальше только точность, баги и репетиции.
