# Демо — 5 минут

| Время | Что показываем | Готово? |
|---|---|---|
| 0:00–1:00 | Интерфейс, список, выбранный диалог (лучше KZ или звонок — показать мультиязычность) | ⬜ |
| 1:00–3:00 | Оценка: критерии, обоснования, клик → реплика подсветилась; пример **N/A** с причиной; итог с перераспределением веса | ⬜ |
| 3:00–4:00 | Апелляция → проверяющий меняет оценку + причина → новый итог (исходная / решение / финал) | ⬜ |
| 4:00–5:00 | Замена критерия в редакторе → сохранить → перезапуск оценки → новый результат | ⬜ |

> [!tip] Подготовить заранее
> - Заранее выбранные диалоги: с N/A, с грубой ошибкой, звонок.
> - Контрольный набор уже прогнан к выступлению.
> - Фраза про точность: «на нашей разметке DEV совпадение X%, MAE Y».
> - Фраза про стоимость одной оценки.
> - Запасной план при падении API/LLM: результаты в БД уже есть, кнопка «перезапустить» показывает живой прогон.
