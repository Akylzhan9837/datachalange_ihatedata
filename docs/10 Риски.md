# Риски

| Риск | Вероятность | Что делаем |
|---|---|---|
| API организаторов недоступен на T+23 | средняя | загрузка JSON-файлом в UI; локальная копия DEV |
| Лимиты/падение облачной LLM | средняя | ретраи с backoff, второй провайдер, пакет запускать сразу |
| Замена критерия ломает промпт | высокая без репетиции | промпт из конфига, репетиция в [[08 Демо]] |
| Модель «добрая» на шкалах | высокая | калибровка по GT, явные анти-примеры в промпте |
| Не успеваем UI | средняя | фича-фриз T+20, приоритет обязательным R-xx |
| Подозрение в заготовленных ответах | низкая | живой запуск на демо, версия чек-листа в каждом результате, лог вызовов |
